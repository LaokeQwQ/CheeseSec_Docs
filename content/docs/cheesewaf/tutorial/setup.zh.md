首次启动 CheeseWAF 后，需通过 Web 初始化向导完成安全基线与凭据设置：

{{% steps %}}

### 1. 访问初始化向导 {#open-wizard}

- **本地或主机部署**：在浏览器中打开 `http://127.0.0.1:9443/setup`。
- **Docker 容器部署**：访问 `https://<服务器IP>:9443/setup`（首次访问需在浏览器中信任自签名证书）。

若控制台或服务日志中输出了初始化 Token，请在页面提示框中填入该令牌以验证管理员权限。

### 2. 创建管理员账号与安全密钥保存 {#create-admin}

输入管理员用户名并设置符合复杂度要求的强密码。向导在完成初始化时将生成并展示系统主密钥与安全凭证，请务必妥善记录并安全归档，系统后续将不再以明文方式展示该凭据。

### 3. 配置管理平面网络边界 {#confirm-listener}

- 在单机或内部部署场景下，建议将 `server.admin_listen` 保持为本地回环地址（`127.0.0.1:9443`）。
- 仅在已配置受信 TLS 证书并具备严格网络访问控制列表（ACL）的前提下，方可将 `server.admin_public` 设置为 `true`。

{{% /steps %}}

完成初始化向导后，访问管理地址将自动重定向至 Web 控制台登录页。此外，也可通过终端交互工具 `waf-cli` 或命令行 `cheesewaf user` 管理本地用户账号。
