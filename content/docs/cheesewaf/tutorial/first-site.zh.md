登录 Web 控制台后，进入 **站点管理** → **新建站点**，按以下步骤配置业务反向代理：

{{% steps %}}

### 1. 配置业务域名 {#domain}

在域名列表中填入对外提供服务的主机名（如 `app.example.com`）。CheeseWAF 将使用配置的 `sites[].domains` 列表匹配入站请求的 HTTP `Host` 请求头。

### 2. 配置上游源站 {#upstream}

填入后端真实的源站服务器地址与端口（如 `10.0.0.10:8000`）。当配置多个上游源站时，系统将默认采用轮询算法（`round_robin`）执行负载均衡分发。

### 3. 设置初始防护等级 {#paranoia}

新建站点默认使用防护等级 **3（智能标准模式）**；如果当前版本的向导显示该选项，请保持为 3。该等级会当场阻断高置信度的独立攻击载荷，对夹杂在长文本中的可疑特征执行放行并异步投递 ALAP 审查，兼顾安全性与业务连续性。

### 4. 保存与热加载配置 {#save}

点击保存站点。CheeseWAF 支持站点配置的动态热加载，规则生效无需重启主服务进程。

{{% /steps %}}

配置完成后，修改本地 hosts 文件或调整 DNS 解析，将域名指向 CheeseWAF 数据平面的监听地址（默认 `http://127.0.0.1:8080`），验证业务流量能否正常回源代理。

关于健康检查、SSL 证书自动申请及路径重写等高级配置，请参考 [站点与反向代理配置](../../sites/)。
