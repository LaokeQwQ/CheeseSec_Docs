首次安装 CheeseWAF 后，系统尚未生成管理员凭证与业务站点配置。CheeseWAF 提供 **Web 图形向导** 与 **终端 CLI 向导** 两种初始化方式，用户可根据部署场景自由选择。

## 方式一：终端命令行初始化向导（推荐运维使用） {#cli-setup}

在终端中执行以下命令即可启动轻量级交互式向导：

```bash
cheesewaf setup
```

### 1. 自动化硬件探测与画像适配

向导启动时会自动探测主机的计算与存储资源（CPU 核心数、物理可用内存及磁盘挂载容量），并智能推荐最适配的运行画像（Hardware Profile）：

- **`minimal`（轻量模式）**：适合 1~2 核 CPU、<2GB 内存的轻量虚拟机或边缘路由器，调低内存缓冲区。
- **`balanced`（均衡模式）**：适合 4~8 核、4~16GB 内存的标准生产服务器，平衡检测吞吐与并发连接数。
- **`performance`（高性能模式）**：适合 16+ 核以上高性能计算节点，启用全量并发 Worker 线程池与激进缓存。

### 2. 交互式凭据录入与安全事务保障

- **凭证设置**：输入超级管理员用户名并输入强密码（向导会执行密码复杂度检查）。
- **外部遥测配置**：可选一键开启 GeoIP 数据库同步、Prometheus `/metrics` 监控端点或 VictoriaLogs 日志外发。
- **事务性安全承诺**：向导在最终步骤确认前，所有配置仅在内存状态中收集。**若在任意一步中断退出，系统绝不触碰磁盘，杜绝残留任何半初始化脏配置**。

### 3. 脚本无交互自动化（Headless Mode）

在 CI/CD 自动化流水线或云主机批量装机时，可传入命令行标志实现全自动无人值守初始化：

```bash
cheesewaf setup --yes \
  --username admin \
  --password-stdin < /etc/cheesewaf/secrets/admin_pass.txt \
  --profile balanced \
  --admin-listen 127.0.0.1:9443 \
  --skip-probe
```

## 方式二：Web 浏览器图形向导 {#web-setup}

{{% steps %}}

### 1. 打开初始化向导网页

- **本地物理机或开发环境**：使用浏览器打开 `http://127.0.0.1:9443/setup`。
- **云服务器或 Docker 容器**：访问 `https://<服务器IP>:9443/setup`（若启用了自签名 TLS，首次需在浏览器中信任临时证书）。

### 2. 创建管理员账号与安全凭据

根据图形页面步骤指引：
1. 录入初始超级管理员账号与密码（需包含大小写字母、数字及特殊符号）。
2. 向导将展示系统主加密密钥与管理员凭证摘要，请妥善保存归档。

### 3. 配置管理网络边界

- 生产单机环境中建议将管理监听（`server.admin_listen`）绑定至本地回环地址（`127.0.0.1:9443`）。
- 若确需跨公网访问 Web 控制台，请保持启用 `server.admin_tls` 并配置受信的 SSL 证书与访问控制白名单。

{{% /steps %}}

完成初始化向导后，访问管理地址将自动重定向至 Web 控制台登录页。后续可通过终端交互工具 `waf-cli` 或命令行 `cheesewaf user` 随时重置管理员密码。
